# 影视解说博主标准创作 SOP (Workflow SOP)

> 🎥 爆款短剧与电影解说的标准化高效创作流

---

## 阶段 1：素材拆条与高光准备
- 将 2 小时电影导入 Asset Hub。
- 在搜索框输入高潮台词（如“真相只有一个”），将命中的片段打上 `高潮` 或 `反转` 标签。

## 阶段 2：剧本精炼与 Hook 设计
- 在 Script Studio 中，先编写前 3 秒 `🪝 黄金 Hook 卡`（例如将电影最震撼的 3 秒画面前置作为倒叙）。
- 检查配音时长统计，将整篇解说控制在 3-5 分钟的爆款区间。

## 阶段 3：音画对齐与消重导出
- 在 Workspace 中确认剧本与画面对齐后，进入 Export Hub 勾选 `微距呼吸缩放` 与 `胶片微噪点`。
- 执行发布合规扫描并一键导出到平台。
