# 30 秒快速上手 (Quick Start)

> ⚡ 快速创建您的第一个 AI 影视解说工程

---

## 一、3 步极速创建工程

1. **点击新建**：在控制台首页或项目列表点击「新建项目」。
2. **填写表单与导入**：输入项目名称与描述，拖入待剪辑的 MP4/MOV 影视原片。
3. **确认直达工坊**：点击「创建工程并进入素材工坊」，系统自动跳转至素材拆条工坊开启创作。

---

## 二、四大工坊流转 SOP

```
[新建项目] → 1. 素材拆条 (挑选镜头/搜索台词) → 2. 剧本研磨 (Hook卡/配音预估) → 3. 剪辑合成 (以文剪片) → 4. 消重发布 (指纹消重/矩阵发布)
```
