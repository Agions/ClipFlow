# 剧本研磨工坊指南 (Script Studio)

> 🎭 结构化剧本骨架卡片、TTS 配音时长预估与多 Agent 协同创作

---

## 一、结构化剧本骨架卡片设计

摒弃传统的纯大文本框设计，剧本研磨工坊采用模块化场景卡片：

- **🪝 黄金 3 秒 Hook 卡**：针对短视频完播率设计前置悬念倒叙或高潮画面。
- **📖 主线递进卡**：铺展剧情起因与角色矛盾。
- **🔥 高潮反转卡**：关键剧情转折与冲突爆发。
- **🎯 互动结尾卡**：引导观众点赞、关注与评论互动。

---

## 二、关键功能

- **TTS 配音时长实时估算**：根据中文 4 字/秒的朗读速率，实时预估单段及整篇视频的配音时长（秒），帮助博主在撰写阶段把控全片节奏。
- **多 Agent 协同润色**：解说编剧 Agent、黄金 Hook Agent 与情绪节奏 Agent 随时提供 AI 润色与续写功能。
