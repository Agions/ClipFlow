## 一、5 级智能指纹消重滤镜

1. **微距呼吸缩放**：1.02x ~ 1.05x 正弦周期动态平滑缩放，规避画面静态帧比对。
2. **电影胶片微噪点**：动态注入 3% 胶片银盐颗粒，打散哈希指纹。
3. **智能光影重构**：微调色阶曲线与高光分布。
4. **动态氛围画中画**：背景高斯模糊与多图层合成（适配 9:16 / 16:9 / 1:1 画幅）。
5. **镜头水平动态镜像**：智能识别字幕区域，仅在无文字镜头处智能翻转画面。
