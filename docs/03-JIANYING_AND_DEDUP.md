# 剪映草稿协议与 5 级防搬运消重管线

## 1. 剪映草稿导出器 (JianYing Exporter)

剧工支持将工作台中的创作工程无损导出为剪映工程草稿目录结构：

```
[剪映草稿目录]/
├── draft_content.json      # 核心轨道拓扑 (主视频轨、音频轨、字幕轨、特效轨)
├── draft_meta_info.json    # 草稿元数据 (名称、创建时间、草稿封面、时长、帧率)
└── draft_cover.png         # 自动截取的 4K 封面帧
```

## 2. 5 级反爬指纹消重滤镜链

针对主流平台（抖音、快手、小红书、视频号、B站）的反爬指纹检测算法，剧工内置 5 级消重管线：

1. **动态微缩放与微平移**：以 0.98x - 1.02x 动态微变焦，打破固定画面哈希；
2. **画中画背景高斯模糊**：自动提取边缘色彩作为背景虚化层，自适应 9:16 / 16:9 画幅；
3. **胶片颗粒抗指纹微噪点**：在不可感知范围内注入模拟胶片噪点与像素微扰；
4. **人声音频 EQ 均衡调优**：人声微调增强、背景氛围音多频段微移；
5. **元数据擦除与重构**：擦除原始 EXIF / 编码器指纹，写入专属版权水印签名。
