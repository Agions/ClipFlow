# 常见问题与排错手册 (FAQ)

## 1. 运行与安装常见问题

### Q1: macOS 提示「已损坏，无法打开」或「无法验证开发者」？
- **原因**：由于 macOS Gatekeeper 安全策略对未签名应用的限制。
- **解决方案**：
  打开终端执行以下命令并输入电脑密码：
  ```bash
  sudo xattr -rd com.apple.quarantine /Applications/Fablr.app
  ```

### Q2: Windows 打开时提示缺少 WebView2 运行时？
- **解决方案**：前往微软官网下载并安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 即可。

## 2. 核心工坊创作与排错

### Q3: 为什么导入的短剧视频没有切片或切片较少？
- **排查步骤**：
  1. 检查源视频是否画面变动极小（如纯录屏或 PPT 演讲）；
  2. 在设置中将「切片灵敏度」从标准调至「高敏感」；
  3. 确保视频文件未受损坏，可在本地播放器正常播放。

### Q4: 导出的剪映草稿在剪映中打开提示「素材丢失」？
- **原因**：剪映草稿通过相对/绝对路径引用本地视频源文件。
- **解决方案**：
  1. 请勿在导出后移动或重命名导入的原片视频；
  2. 若已移动，在剪映弹出的提示窗口中点击「重新定位」，选择新位置下的视频文件即可瞬间恢复所有轨道。

### Q5: AI 剧本生成时提示 API 请求超时？
- **排查步骤**：
  1. 前往「设置中心」检查 API Key 与 Base URL 是否正确填写；
  2. 若使用境外大模型服务，请确保本地代理网络畅通；
  3. 推荐使用国内快速大模型（如 DeepSeek V3/R1）。
