# 桌面端全功能快捷键清单

Fablr (剧工) 专为专业后期与高效创作者设计了全键盘盲操快捷键体系，覆盖全局导航、5 轨时间轴与剧本工坊。

---

## 1. 全局导航与系统操作

| 快捷键 (macOS) | 快捷键 (Windows/Linux) | 功能描述 |
| :--- | :--- | :--- |
| `Cmd + 1` | `Ctrl + 1` | 跳转至 **素材拆条工坊 (Asset Hub)** |
| `Cmd + 2` | `Ctrl + 2` | 跳转至 **剧本研磨工坊 (Script Studio)** |
| `Cmd + 3` | `Ctrl + 3` | 跳转至 **5 轨剪辑工作台 (Workspace)** |
| `Cmd + 4` | `Ctrl + 4` | 跳转至 **消重发布工坊 (Export Hub)** |
| `Cmd + S` | `Ctrl + S` | 立即触发原子化强制保存 |
| `Cmd + /` | `Ctrl + /` | 打开/关闭 快捷键帮助清单弹窗 |

---

## 2. 5 轨时间轴专业剪辑

| 快捷键 | 作用域 | 功能描述 |
| :--- | :--- | :--- |
| `Space` | 时间轴 / 监视器 | 播放 / 暂停视听预览 |
| `J` | 时间轴 | 倒放 (多次按下 2x / 4x 倒放) |
| `K` | 时间轴 | 暂停播放 |
| `L` | 时间轴 | 正向播放 (多次按下 2x / 4x 倍速快进) |
| `S` | 时间轴 | **一键剪切**：在游标位置切断当前选中轨道片段 |
| `Delete` / `Backspace` | 时间轴 | 删除当前选中的视频/音频切片 |
| `Cmd + Z` / `Ctrl + Z` | 全局 | 撤销上一步操作 (Undo) |
| `Cmd + Shift + Z` | 全局 | 重做下一步操作 (Redo) |
| `+` / `=` | 时间轴 | 放大时间轴刻度（提升微调精度） |
| `-` | 时间轴 | 缩小时间轴刻度（查看全片节奏） |

---

## 3. 剧本工坊快捷操作

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Cmd + Enter` / `Ctrl + Enter` | 立即触发 AI 剧本一键研磨 / 续写 |
| `Tab` | 快速聚焦至下一个骨架卡片输入框 |
| `Esc` | 取消当前弹窗 / 收起当前卡片 |
