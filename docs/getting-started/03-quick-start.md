# 5 分钟极速上手实战

本教程将带领您通过「Fablr 4 大工坊」工作流，在 5 分钟内将一段长视频/短剧原片制作成一条高爆款潜力的影视解说视频并导出剪映工程。

---

## 步骤 1：新建项目与素材导入 (Asset Hub)

1. 打开 Fablr 客户端，点击首页右上角 **「新建创作项目」**；
2. 输入项目名称（如 `《绝命狂飙》第1集解说`），选择解说赛道风格（如 `短剧爽感反转`）；
3. 系统将自动进入 **「素材拆条工坊 (Asset Hub)」**；
4. 点击中栏 **「批量导入素材」**，选中您的原片视频文件（支持 `.mp4`, `.mov`, `.mkv`）；
5. 本地 Whisper 引擎与镜头探测器将自动工作：
   - 自动切分出 10~30 个高清镜头片段；
   - 提取原片台词字幕并打上情感标签（`打斗 🥊`、`悬疑 🔍`、`高潮 💥`）。

---

## 步骤 2：多 Agent 剧本研磨 (Script Studio)

1. 点击顶部导航栏或右上角按钮 **「前往剧本工坊」**；
2. 在右侧属性栏选择模板（如 `⚡ 战神逆袭打脸模板` 或 `🎭 情感伦理深度模板`）；
3. 点击 **「一键研磨剧本」**：
   - **策划 Agent** 自动提炼前 3 秒黄金 Hook；
   - **编剧 Agent** 生成「主线递进」与「高潮反转」段落；
   - **审校 Agent** 润色台词，优化口语化表达与 TTS 语速；
4. 查看每张卡片的 **配音时长预估**，可直接在输入框内修改台词，右下角字数与配音时长将实时联动更新。

---

## 步骤 3：以文剪片与时间轴对齐 (Workspace)

1. 点击右上角 **「去剪辑合成 →」**，进入 **「5 轨视听剪辑工作台」**；
2. 切换至 **「以文剪片」** 视图，左侧为结构化剧本文本，右侧为 16:9 实时监视器；
3. 点击任意剧本卡片，系统将根据镜头爆点分自动将最契合的视频切片吸附到 `V1 主视频轨`；
4. 切换至 **「5 轨时间轴」** 视图：
   - 查看 `V1 画面`、`V2 画中画`、`A1 解说配音`、`A2 情绪 BGM`、`A3 动作音效` 轨道；
   - 拖拽播放游标或按空格键实时预览视听效果。

---

## 步骤 4：消重矩阵与剪映草稿导出 (Export Hub)

1. 点击顶部工坊步骤条 **「4. 消重发布」** 进入导出中心；
2. 在左侧面板勾选所需消重策略（推荐开启 `微调变速 1.03x` + `动态微噪点` + `画中画氛围光`）；
3. 选择导出目标：
   - **导出剪映草稿工程 (推荐)**：直接将工程注入本机剪映草稿目录，打开剪映即可立即进行二次精细化贴纸、特效与花字编辑；
   - **直接渲染合成 MP4**：本地 FFmpeg 硬件加速直接渲染出成片。

🎉 **恭喜！您已成功完成第一部 AI 影视解说作品的创作！**
