# 产品定位与核心价值

## 1. 业务背景与行业痛点

在短视频、短剧解说与影视二创赛道，创作者通常面临以下核心瓶颈：

1. **工作流割裂，工具链路冗长**：
   - 传统工作流：`下载原片 → 导入播放器人工逐帧找亮点 (2小时) → Word/飞书写解说稿 (1小时) → 导入剪映/PR 人工对齐音画切片 (3小时) → 人工微调画面防违规 (30分钟)`。平均单条视频耗时 6 小时以上。
2. **多 Agent 协同能力缺失**：
   - 现存 AI 工具多数仅提供单一通用大模型对话框，生成的文案缺乏影视解说的「黄金 3 秒 Hook」、「反转冲突」和「口语化节奏感」，无法直接用于配音。
3. **平台查重与消重合规风险**：
   - 各大短视频平台对影视短剧搬运查重极其严格，单纯的画面缩放或简单抽帧极易被判定「低质搬运」或「侵权下架」。
4. **云端安全与本地隐私担忧**：
   - 商业化短剧素材与未公开样片上传至第三方云端服务器存在版权和数据泄露风险。

## 2. 剧工 (Fablr) 的解题思路

**Fablr (剧工)** 定位为**开源桌面级 AI 影视/短剧解说创作工坊**。采用 **Tauri 2 + Rust + React 18** 现代化技术架构，以「本地优先 (Local-First)」为设计准则，提供贯穿从**素材导入**到**全平台合规发布**的全生命周期工业级创作工作流。

## 3. 四大核心工坊概览

### 🎬 工坊 1：智能素材拆条 (Asset Hub)
- **毫秒级切片与转写**：基于本地 Whisper 离线模型提取原片全量台词与时间戳。
- **智能镜头切点探测**：自动识别镜头边界与画面景别（特写/全景/打斗/空镜）。
- **情绪爆点与密度打分**：按台词情绪与视觉动态强度对切片进行 0-100 分量化评级。

### 🤖 工坊 2：多 Agent 剧本研磨 (Script Studio)
- **工业级 4 段骨架**：拒绝平铺长文，强制拆解为「🪝 黄金3秒 Hook + 📖 主线递进 + 🔥 高潮反转 + 🎯 互动结尾」。
- **多 Agent 流式研磨**：策划 Agent (Director)、编剧 Agent (Writer)、合规审校 Agent (Reviewer) 协作推演。
- **TTS 配音时长实时感知**：按中文 4 字/秒自然语速实时计算配音时长，确保音画时长精准匹配。

### 🎛️ 工坊 3：5 轨视听剪辑工作台 (Workspace)
- **Canvas + RAF 虚拟化时间轴**：即便承载数百个切片与复杂音频波形，依然保持 60 FPS 丝滑缩放与拖拽。
- **以文剪片 (Text-Driven Editing)**：点击剧本文本卡片，自动将对应视频镜头、ASR 台词与背景音乐吸附对齐。
- **专业 5 轨架构**：`V1 画面主轨`、`V2 画中画/光影轨`、`A1 解说配音轨`、`A2 情绪 BGM 轨`、`A3 动作音效 FX 轨`。

### 🛡️ 工坊 4：消重发布工坊 (Export Hub)
- **5 级消重矩阵**：镜像翻转、微调变速 (1.02x-1.08x)、动态噪点注入、画中画氛围光与智能抽帧。
- **剪映草稿逆向导出**：一键生成标准 `draft_content.json`，在剪映中打开即可保留全部图层、关键帧与文字样式进行二次微调。

## 4. 与传统解决方案对比

| 评估维度 | 传统手工剪辑 (PR/剪映) | 通用云端 AI 工具 | Fablr (剧工) 创作工坊 |
| :--- | :--- | :--- | :--- |
| **单条解说耗时** | 4 ~ 6 小时 | 1 ~ 2 小时 (需手工搬运素材) | **5 ~ 10 分钟 (全流程闭环)** |
| **素材与文案匹配** | 手工逐帧寻找对齐 | 需人工二次比对 | **以文剪片，镜头与文稿自动对齐** |
| **剧本专业度** | 依赖博主个人经验 | 通用大白话，无节奏感知 | **4段结构化骨架 + 黄金3秒公式** |
| **消重合规能力** | 人工调色加滤镜 (易漏) | 无 | **5 级参数化消重矩阵** |
| **数据与隐私安全** | 本地安全 | 上传云端存在泄露风险 | **100% 本地运行，零网络依赖** |
| **二次精剪自由度** | 高 | 仅输出压制 MP4，无法二次修改 | **导出剪映原生全轨工程** |
